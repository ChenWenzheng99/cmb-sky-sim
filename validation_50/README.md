# Current CMB ensemble check

The companion manuscript reports 50 native NSIDE2048 realizations (IDs 0–49),
with multipoles below 1000. `paper_cmb50_table.csv` and
`independent_ensemble_review.json` record that comparison. The shaded intervals
represent the sample standard deviation, with `ddof=1`.

The CMB subpackage retains its original ten-realization acceptance records as
historical generation evidence. Those records do not replace this later
50-realization manuscript analysis, and neither analysis validates all 500
skies at every multipole. No fitted BB amplitude is applied to the maps.
